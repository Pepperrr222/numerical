## 第一步：点与闭凸集的严格分离（核心引理）

**引理**：设 $C \subseteq \mathbb{R}^n$ 为非空闭凸集，$\mathbf{x}_0 \notin C$。则存在超平面严格分离 $\mathbf{x}_0$ 与 $C$。

### 证明

**1. 构造投影点**

考虑投影问题：

$$\mathbf{p} = P_C(\mathbf{x}_0) = \arg\min_{\mathbf{x} \in C} \|\mathbf{x} - \mathbf{x}_0\|_2$$

由于 $C$ 为非空闭集且 $\mathbf{x}_0 \notin C$，该最小值**可达**且 $\mathbf{p} \neq \mathbf{x}_0$（若为紧集，由连续函数极值定理；一般闭凸集需用完备性论证）。

**2. 投影的变分不等式**

$C$ 的**凸性**保证投影具有如下关键性质：

$$(\mathbf{x}_0 - \mathbf{p})^T(\mathbf{x} - \mathbf{p}) \leq 0, \quad \forall \mathbf{x} \in C$$

> **推导**：对任意 $\mathbf{x} \in C$，由 $C$ 凸性，对 $t \in (0,1]$ 有 $\mathbf{p} + t(\mathbf{x} - \mathbf{p}) \in C$。由 $\mathbf{p}$ 的最优性：
>
> $$\|\mathbf{p} + t(\mathbf{x}-\mathbf{p}) - \mathbf{x}_0\|^2 \geq \|\mathbf{p} - \mathbf{x}_0\|^2$$
>
> 展开并令 $t \to 0^+$ 即得。

**3. 构造分离超平面**

取：
$$\mathbf{a} = \mathbf{x}_0 - \mathbf{p} \neq \mathbf{0}, \quad b = \mathbf{a}^T \mathbf{p}$$

**4. 验证分离条件**

对任意 $\mathbf{x} \in C$：

$$\mathbf{a}^T \mathbf{x} = \mathbf{a}^T \mathbf{p} + \mathbf{a}^T(\mathbf{x} - \mathbf{p}) = b + (\mathbf{x}_0 - \mathbf{p})^T(\mathbf{x} - \mathbf{p})$$

由变分不等式：

$$\mathbf{a}^T \mathbf{x} \leq b$$

而对 $\mathbf{x}_0$：

$$\mathbf{a}^T \mathbf{x}_0 = \mathbf{a}^T(\mathbf{p} + \mathbf{a}) = b + \|\mathbf{a}\|^2 > b$$

因此：

$$\mathbf{a}^T \mathbf{x} \leq b < \mathbf{a}^T \mathbf{x}_0, \quad \forall \mathbf{x} \in C$$

即超平面 $\{\mathbf{x} \mid \mathbf{a}^T \mathbf{x} = b\}$ **严格分离** $\mathbf{x}_0$ 与 $C$。$\blacksquare$

## 第二步：一般超平面分离定理

**定理**：设 $C, D \subseteq \mathbb{R}^n$ 为非空凸集，$C \cap D = \varnothing$。则存在 $\mathbf{a} \neq \mathbf{0}$ 和 $b \in \mathbb{R}$，使得：

$$\mathbf{a}^T \mathbf{x} \leq b \leq \mathbf{a}^T \mathbf{y}, \quad \forall \mathbf{x} \in C, \forall \mathbf{y} \in D$$

### 证明

**1. 构造 Minkowski 差集**

定义：
$$S = C - D = \{\mathbf{x} - \mathbf{y} \mid \mathbf{x} \in C, \mathbf{y} \in D\}$$

- **凸性**：$S$ 是凸集。因为 $C, D$ 均为凸集，Minkowski 差保持凸性。

- **非空**：$C, D$ 均非空，故 $S \neq \varnothing$。

- **原点不在 $S$ 中**：
$$\mathbf{0} \in S \iff \exists \mathbf{x} \in C, \mathbf{y} \in D, \text{ s.t. } \mathbf{x} = \mathbf{y} \iff C \cap D \neq \varnothing$$

  由假设 $C \cap D = \varnothing$，故 $\mathbf{0} \notin S$。

**2. 闭化处理**

若 $S$ 闭，直接对 $\{\mathbf{0}\}$（紧凸集）与 $S$（闭凸集）应用第一步引理。

若 $S$ 不闭，取闭包 $\bar{S} = \text{cl } S$：

- $\bar{S}$ 仍为凸集（闭包保持凸性）
- $\mathbf{0} \notin \bar{S}$（$\mathbf{0} \notin S$ 且可证明在此条件下 $\mathbf{0} \notin \text{cl } S$；更精确地说，需分情况讨论）

> **严格性说明**：若 $\mathbf{0} \in \bar{S} \setminus S$，则只能得到非严格分离。这是"分离≠严格分离"的根本原因。

**3. 应用第一步**

由第一步引理，存在 $\mathbf{a} \neq \mathbf{0}$ 和 $b$，使得：

$$\mathbf{a}^T \mathbf{z} \leq b < 0 = \mathbf{a}^T \mathbf{0}, \quad \forall \mathbf{z} \in S$$

（这里取 $\mathbf{0}$ 处严格不等式）。

**4. 回到 $C$ 与 $D$**

对任意 $\mathbf{x} \in C$，$\mathbf{y} \in D$，有 $\mathbf{x} - \mathbf{y} \in S$，故：

$$\mathbf{a}^T(\mathbf{x} - \mathbf{y}) \leq b \implies \mathbf{a}^T \mathbf{x} \leq \mathbf{a}^T \mathbf{y} + b$$

取上确界：

$$\sup_{\mathbf{x} \in C} \mathbf{a}^T \mathbf{x} \leq \inf_{\mathbf{y} \in D} \mathbf{a}^T \mathbf{y}$$

选 $b$ 满足：

$$\sup_{\mathbf{x} \in C} \mathbf{a}^T \mathbf{x} \leq b \leq \inf_{\mathbf{y} \in D} \mathbf{a}^T \mathbf{y}$$

即：

$$\mathbf{a}^T \mathbf{x} \leq b \leq \mathbf{a}^T \mathbf{y}, \quad \forall \mathbf{x} \in C, \forall \mathbf{y} \in D$$

$\blacksquare$

---

## 第三步：严格分离的充分条件

**定理**：若 $C$ 为闭凸集，$D$ 为紧凸集，$C \cap D = \varnothing$，则存在**严格**分离超平面。

### 证明要点

- $C$ 闭、$D$ 紧 $\implies$ $C - D$ 为闭集（闭集减紧集是闭集）。
- 因此 $\bar{S} = S$，原点 $\mathbf{0} \notin S = \bar{S}$。
- 直接应用第一步，得到严格分离。 $\blacksquare$

---

## 证明结构总结

```
核心：投影定理 + 凸性
         │
         ▼
  点 vs 闭凸集的严格分离（变分不等式）
         │
         ▼
  构造 Minkowski 差集 S = C − D
  将"两个集合分离"转化为"原点与一个集合分离"
         │
         ▼
  一般分离定理
         │
    ┌────┴────┐
    ▼         ▼
  非严格分离   严格分离
 （S 不闭时）  （C 闭、D 紧时）
```

整个证明的**几何直觉**是：将"两个凸集之间的间隙"编码为 $\mathbb{R}^n$ 中的一个凸集 $S$，然后用**欧几里得投影**（最近点）的法向量构造分离超平面的法方向。凸性保证了投影的变分不等式成立，这正是分离条件的代数来源。
